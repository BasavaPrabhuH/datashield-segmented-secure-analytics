# S3

The DataShield S3 bucket stores processed files.

The report states that the bucket uses:
- Versioning
- Lifecycle management
- Public-access restriction
- Server-side/default encryption
- Object events that trigger Lambda
- Processed-object storage under the processed workflow

Use placeholders for the bucket name in published examples.

## Verification

```bash
aws s3api get-bucket-versioning --bucket <S3_BUCKET_NAME>
aws s3api get-public-access-block --bucket <S3_BUCKET_NAME>
aws s3api get-bucket-encryption --bucket <S3_BUCKET_NAME>
aws s3api get-bucket-lifecycle-configuration --bucket <S3_BUCKET_NAME>
aws s3api get-bucket-notification-configuration --bucket <S3_BUCKET_NAME>
```
